# Решение проблемы с портом 3000

## Проблема
Порт 3000 занят Docker контейнером или другим процессом.

## Решения

### Вариант 1: Запустить Rails на другом порту (рекомендуется)

1. Запустите Rails на порту 3001:
```bash
cd ~/wlmini/web_app
rails server -p 3001
```

2. Перезапустите ngrok на порт 3001:
   - Остановите текущий ngrok: `Ctrl+C`
   - Запустите: `ngrok http 3001`

3. Используйте новый URL из ngrok

### Вариант 2: Остановить Docker контейнер

1. Найдите контейнер:
```bash
docker ps
```

2. Остановите контейнер:
```bash
docker stop <container_id>
```

3. Запустите Rails на порту 3000:
```bash
cd ~/wlmini/web_app
rails server
```

### Вариант 3: Использовать порт 80

Если ngrok настроен на порт 80:

```bash
cd ~/wlmini/web_app
sudo rails server -p 80
```

(Требует sudo)

## Проверка

После настройки откройте URL из ngrok в браузере - должно работать!
