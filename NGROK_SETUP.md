# Настройка ngrok для Rails приложения

## Текущая ситуация

- Ngrok перенаправляет на: `localhost:80`
- Rails по умолчанию работает на: `localhost:3000`

## Решение

### Вариант 1: Запустить Rails на порту 80 (рекомендуется)

1. Остановите текущий ngrok (если запущен): `Ctrl+C`

2. Запустите Rails на порту 80:
```bash
cd ~/wlmini/web_app
sudo rails server -p 80
```

3. Запустите ngrok на порту 80:
```bash
ngrok http 80
```

4. Используйте URL из ngrok для доступа к приложению

### Вариант 2: Перезапустить ngrok на порт 3000

1. Остановите текущий ngrok: `Ctrl+C`

2. Запустите ngrok на порту 3000:
```bash
ngrok http 3000
```

3. Запустите Rails (по умолчанию на порту 3000):
```bash
cd ~/wlmini/web_app
rails server
```

4. Используйте URL из ngrok для доступа к приложению

### Вариант 3: Использовать переменную окружения PORT

1. Запустите Rails на нужном порту:
```bash
cd ~/wlmini/web_app
PORT=80 rails server
```

2. Или для порта 3000:
```bash
PORT=3000 rails server
```

3. Настройте ngrok соответственно

## Проверка

После настройки откройте URL из ngrok в браузере:
```
https://tanna-interungular-unpresumptively.ngrok-free.dev
```

Должна открыться главная страница с вишлистами.

## Примечание

Если используете порт 80, может потребоваться права sudo. Альтернатива - использовать порт 3000 и настроить ngrok соответственно.
