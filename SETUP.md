# Инструкция по настройке

## Требования

- Ruby ~3.0
- Node.js (версия 14+)
- PostgreSQL
- Bundler для Ruby
- npm или yarn для Node.js

## Настройка баз данных

### 1. Создать базы данных PostgreSQL

```bash
# Подключиться к PostgreSQL
psql -U postgres

# Создать базы данных
CREATE DATABASE wishlist_bot_db;
CREATE DATABASE wishlist_web_db;

# Выйти
\q
```

## Настройка Telegram Bot

1. Перейти в директорию бота:
```bash
cd telegram_bot
```

2. Установить зависимости:
```bash
bundle install
```

3. Настроить переменные окружения (файл `.env` уже создан с токеном):
```bash
# Проверить, что токен указан в .env
cat .env
```

4. Создать базу данных (если еще не создана):
```bash
rake db:create
```

5. Запустить миграции:
```bash
rake db:migrate
```

6. Запустить бота:
```bash
ruby bot.rb
```

## Настройка Web App

1. Перейти в директорию веб-приложения:
```bash
cd web_app
```

2. Установить зависимости:
```bash
npm install
# или
yarn install
```

3. Создать директорию для загрузок:
```bash
mkdir -p uploads
```

4. Запустить миграции:
```bash
npm run migrate
# или
node scripts/migrate.js
```

5. Запустить сервер:
```bash
npm start
# или для разработки с автоперезагрузкой:
npm run dev
```

Веб-приложение будет доступно по адресу: http://localhost:3000

## Использование

### Веб-приложение

1. Откройте http://localhost:3000 в браузере
2. Создайте вишлист с названием и датой события
3. Добавьте подарки в вишлист (можно добавить изображение, ссылку, цену и дополнительную информацию)

### Telegram Bot

1. Найдите бота в Telegram по имени (нужно создать бота через @BotFather)
2. Отправьте команду `/start` для регистрации
3. Бот будет автоматически напоминать о событиях:
   - За 7 дней до события
   - За 3 дня до события
   - В день события

## Примечания

- Бот и веб-приложение используют разные базы данных
- Для синхронизации вишлистов между веб-приложением и ботом можно использовать `SyncService` в боте
- Токен бота уже указан в `.env` файле бота
