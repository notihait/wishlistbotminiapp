# 🚀 Как запустить приложения

## Telegram Bot

### 1. Перейти в директорию бота
```bash
cd ~/wlmini/telegram_bot
```

### 2. Запустить бота
```bash
ruby bot.rb
```

Бот начнет работать и будет отвечать на команды в Telegram.

**Команды бота:**
- `/start` - начать работу с ботом
- `/help` - показать справку

---

## Web App (Ruby on Rails)

### 1. Перейти в директорию веб-приложения
```bash
cd ~/wlmini/web_app
```

### 2. Запустить сервер
```bash
rails server
```

Или короткая версия:
```bash
rails s
```

### 3. Открыть в браузере
Веб-приложение будет доступно по адресу:
**http://localhost:3000**

**Функционал:**
- Создание вишлистов (название и дата события)
- Добавление подарков (название, цена, ссылка, изображение, доп. информация)
- Редактирование и удаление вишлистов и подарков

---

## Одновременный запуск

Для запуска обоих приложений одновременно откройте два терминала:

**Терминал 1 - Бот:**
```bash
cd ~/wlmini/telegram_bot
ruby bot.rb
```

**Терминал 2 - Web App:**
```bash
cd ~/wlmini/web_app
rails server
```

---

## Остановка приложений

Нажмите `Ctrl+C` в терминале, где запущено приложение.

---

## Проверка работы

### Проверить, что бот работает:
1. Найдите бота в Telegram
2. Отправьте команду `/start`
3. Бот должен ответить приветствием

### Проверить, что веб-приложение работает:
1. Откройте браузер
2. Перейдите на http://localhost:3000
3. Должна открыться страница со списком вишлистов

---

## Возможные проблемы

### Бот не запускается:
- Проверьте, что PostgreSQL запущен: `pg_isready`
- Проверьте настройки в `.env`
- Убедитесь, что миграции выполнены: `rake db:migrate`

### Веб-приложение не запускается:
- Проверьте, что порт 3000 свободен
- Проверьте настройки в `config/database.yml`
- Убедитесь, что миграции выполнены: `rails db:migrate`

### Ошибки подключения к БД:
- Проверьте, что PostgreSQL запущен
- Проверьте пароль в `config/database.yml`
- Убедитесь, что БД созданы
